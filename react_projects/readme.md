# React Projects Collection

This folder contains a set of small React learning projects built with Vite. Each app focuses on a different concept in React and frontend development, making it a useful practice space for learning state management, routing, APIs, styling, persistence, and component architecture.

These projects are created for educational learning only and are intentionally simple and beginner-friendly.

## Included Projects

### 1. Counter
A beginner-level app demonstrating basic React state handling.
- Uses `useState` to track a counter value
- Includes Add and Remove actions
- Helps learners understand re-rendering and event handling

### 2. Custom React
A lightweight experiment showing how a React-like render function works behind the scenes.
- Creates a custom `customRender` function
- Uses a plain JavaScript object to represent a DOM element
- Helps explain how React elements map to real DOM nodes

### 3. Currency Converter
A practical app for converting money between currencies.
- Input amount field
- Source and target currency selection
- Swap button to reverse conversion direction
- Fetches live exchange values using an API
- Demonstrates form data handling and reusable components

### 4. LocalStorage Todo Context API
A todo app that stores tasks in the browser using `localStorage`.
- Create, update, delete, and complete todos
- Shared state via React Context API
- Data persists after page refresh
- Good example of app-wide state management without prop drilling

### 5. Password Generator
A utility app for generating secure passwords.
- Custom password length
- Optional numbers and special characters
- Copy-to-clipboard support
- Demonstrates state-driven UI logic and utility patterns

### 6. React Context API
A project focused on sharing data between components without passing props repeatedly.
- Uses `createContext` and a custom hook
- Helps explain global state patterns
- Good example of passing values through a provider

### 7. React Router
A routing-focused app built with `react-router-dom`.
- Navigation using `Link` and `NavLink`
- Reusable layouts
- Route-driven page rendering
- Dynamic data loading patterns

### 8. React Tailwind Props
A styling exercise demonstrating Tailwind-based UI and component props.
- Reusable button patterns
- State-driven styling changes
- Example of combining props with utility classes

### 9. Theme Switcher
A simple dark/light mode project.
- Toggle between light and dark themes
- Uses React state and context
- Applies theme classes globally using the document root
- Demonstrates Tailwind dark mode behavior in practice


## Learning Focus

This collection is a strong beginner-friendly introduction to:
- React fundamentals
- state and props
- hooks such as `useState`, `useEffect`, and custom hooks
- Context API
- component structure and reuse
- routing
- API integration
- local browser persistence
- Tailwind CSS styling
- UI interactivity and event handling

## Educational Use Only

This project collection is created solely for educational purposes. It is not intended for production deployment, commercial use, or as a finalized product template.

## Notes

These apps are intentionally lightweight and focused on understanding core concepts. They are designed to help learners build intuition before moving on to larger real-world applications.
